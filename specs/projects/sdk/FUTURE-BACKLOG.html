What this is

A parking lot for tangential ideas surfaced during day-to-day work. When you're deep in workstream X and notice something that's not part of X but should be worked on someday, capture it here instead of letting it slip.

Tracked items live in specs/projects/sdk/_future-backlog.js — version-controlled, visible to everyone. Drafts added via the form below live in your browser's localStorage only. Once you've decided a draft is real, paste its content into the JS file in a PR to promote it.

Status changes on tracked items are also stored in localStorage as personal overrides (e.g. "I think fb-002 is actually triaged now") — click Reset on a card to drop your override and fall back to the file's status. Promote durable status changes to the JS file in a PR.
