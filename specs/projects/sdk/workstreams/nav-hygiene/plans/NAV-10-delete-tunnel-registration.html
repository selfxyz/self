Why

Two routes — /tunnel/registration/country and /tunnel/registration/id-type — render screens that bypass KYC entirely. Reachable only via DevRouteMenu. No production caller. NAV-01 triage classified both as delete. NAV-10 removes them.

Decisions

Locked in on 2026-05-25. See DECISIONS.md.

  • nav-10-q1-delete-vs-move · Decided

    Delete entirely, or move to /dev/embed-registration/*?

    Delete entirely. Remove App.tsx routes, screen files, DevRouteMenu entries. ~150 LOC removed. Anyone who needs a bypass-KYC dev tool later can re-add it explicitly.

Scope

  • Remove both routes from App.tsx (lines 159, 160).
  • Delete the screen files TunnelCountryPickerScreen.tsx and TunnelIDTypeScreen.tsx.
  • Remove the two corresponding DevRouteMenu entries.
  • Strip the imports from App.tsx.

Confirm no test references the deleted routes before removing.

Out of Scope

  • Other /tunnel/* routes — owned by NAV-08.
  • The TunnelCountryPickerScreen / TunnelIDTypeScreen source files — deleted, not refactored.
  • Any consolidation with self-app country/id-type pickers. If a real embed-mode picker is ever needed, that's a new feature, not a NAV-10 follow-up.

Required Files

  • packages/webview-app/src/App.tsx (lines ~159–160)
  • packages/webview-app/src/screens/tunnel/TunnelCountryPickerScreen.tsx (delete)
  • packages/webview-app/src/screens/tunnel/TunnelIDTypeScreen.tsx (delete)
  • packages/webview-app/src/components/DevRouteMenu.tsx (2 entries)

Approach

Step 1 — Confirm no production caller

Run grep -rn "/tunnel/registration" packages/ app/. Confirm hits only in: App.tsx (the registrations), DevRouteMenu.tsx (the entries), the two screen files themselves. No navigate() calls.

Step 2 — Delete

Remove route registrations, screen files, and DevRouteMenu entries. Mechanical.

Step 3 — Strip imports

Remove the two imports from App.tsx (TunnelCountryPickerScreen, TunnelIDTypeScreen).

Validation

  • grep -rn "TunnelCountryPickerScreen\|TunnelIDTypeScreen" packages/webview-app/src — zero hits.
  • grep -rn "/tunnel/registration" packages/webview-app/src — zero hits.
  • yarn types && yarn build — clean.
  • Manual: DevRouteMenu no longer shows the two entries.
  • Manual: navigating directly to the old path returns the catch-all redirect to /.
