Why

The router does not know which operating mode (self-app, embed, shared) any given route belongs to. Mode coupling is implicit and scattered across ModeBoot, InitialRouteRedirect, and per-screen guards. Before we can add a ModeRoute wrapper (NAV-13), rename the namespace (NAV-08), delete dead sub-flows (NAV-10), or gate dev-only routes (NAV-02), every currently registered path needs an explicit disposition.

NAV-01 produces that disposition table — the canonical reference downstream items consume. This PR is documentation-only. No code in App.tsx, DevRouteMenu.tsx, or any screen file changes. Code changes live in the downstream items that act on the dispositions captured here.
