SelfVerificationRegistry

On-chain boolean identity verification with zero PII leakage. Factory deploys per-app EIP-1167 clones for cross-app nullifier unlinkability.

Without SelfVerificationRegistry

  • Raw Hub V2 leaks name, DOB, nationality on-chain
  • Same nullifier across apps = cross-app linkability
  • Every dApp reimplements verification logic
  • Developers need wallets and gas to integrate

With SelfVerificationRegistry

  • Only boolean result + timestamps stored on-chain
  • Unique clone address = unique scope = unlinkable nullifiers
  • One-line query: factory.isVerified(appId, user)
  • Relayer-funded: devs only need an HTTP API call

Architecture

SelfVerificationFactory

UUPS upgradeable singleton. Deploys one EIP-1167 minimal proxy per app. Each clone gets a unique address = unique Poseidon(addr, seed) scope. Authorized relayers call createApp(); anyone calls isVerified(appId, user).

SelfVerificationApp (clone)

~45-byte proxy per app. Extends SelfVerificationRoot. Stores verifications[user] = {verifiedAt, expiresAt} and nullifierToUser[n] = addr. No PII. Expiry = min(docExpiry, now + maxProofAge).

Hub V2 (ZK Verifier)

Validates zero-knowledge passport proofs off-chain, calls back onVerificationSuccess() on the clone. Demo uses a mock that simulates this callback.

Developer Integration

Register via HTTP API, get an appId. Add <self-verify app-id="42"> to your page. Query on-chain: factory.isVerified(42, user). Done.

The relayer calls factory.createApp(appId, name, config) to deploy an EIP-1167 minimal proxy. Each clone gets a unique contract address, which produces a unique Poseidon scope for nullifier unlinkability. Cost: ~200k gas (~$0.001 on Celo).
In production: user scans passport in Self app, ZK proof is generated, relayer calls clone.verifySelfProof(proof), Hub V2 validates and callbacks. Here, the mock Hub simulates the callback with pre-configured output. No real passport needed.
YYMMDD format (e.g., 311231 = Dec 31, 2031)
Any smart contract or EOA can call factory.isVerified(appId, user). This is the one-line integration point. Returns true if the user has a non-expired verification. No oracle, no off-chain dependency — fully trustless.
Solidity integration example:
interface ISelfVerificationFactory { function isVerified(uint256 appId, address user) external view returns (bool); } contract MyDApp { ISelfVerificationFactory factory = ISelfVerificationFactory(FACTORY_ADDR); function doSomething() external { require( factory.isVerified(MY_APP_ID, msg.sender), "Not verified" ); // ... your logic } }
Sybil resistance: one passport = one nullifier per app. A second wallet trying to use the same passport nullifier on the same app is rejected with DuplicateNullifier.

Cross-app unlinkability: the same passport produces different nullifiers on different apps (different clone address = different Poseidon scope). The dating app can't learn you also verified on the gambling site.
